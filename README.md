# AI株式投資アシスタント & LINE通知システム

毎日の株価追跡、**「なぜ上がった/下がったかのAI解説」**、**「買い推奨度（0〜100%）」**、**「新規上場(IPO)情報」**を自動生成し、LINEへ通知するアプリケーションです。

---

## 📁 フォルダ構成

- **`start_dashboard.bat`** : ダブルクリックでブラウザの銘柄管理画面（ダッシュボード）を起動
- **`send_daily_line.bat`** : ダブルクリックで現在のレポートを生成し、LINEへ即座に送信
- **`app.py`** : 銘柄の検索・追加・削除・プレビューができるWebダッシュボード（Streamlit）
- **`daily_job.py`** : 自動実行用のバックグラウンド通知スクリプト
- **`stock_service.py`** : 日本株・米国株のリアルタイム株価、前日比、関連ニュース取得
- **`ai_analyst.py`** : Gemini APIによる騰落要因の解説 & 買い推奨度スコアリング
- **`line_notifier.py`** : LINE Messaging API送信モジュール
- **`watchlist.json`** : 監視中銘柄リスト（日本株・米国株）
- **`config.json`** : APIキー等の設定ファイル

---

## 🚀 使い方

### 1. Web管理画面を起動する
`start_dashboard.bat` をダブルクリックして起動します。
ブラウザ（`http://localhost:8501`）が自動で開き、以下の操作が可能です：

1. **📋 監視リスト管理**: 現在登録されている日本株・米国株の一覧確認と削除
2. **🔍 銘柄検索・追加**: 企業名や銘柄コード（例: `7203`, `トヨタ`, `NVDA`, `アップル` 等）で検索し、ワンクリックで監視リストに追加
3. **📊 デイリーレポート・LINE送信**: 最新の株価・AI解説・IPO情報をブラウザ上でプレビューし、LINEにテスト送信
4. **⚙️ 設定**: Gemini APIキーやLINEのトークンを入力・保存

---

## 🔑 初期設定（Gemini API & LINE連携）

### ① Gemini APIキーの取得（無料）
1. [Google AI Studio](https://aistudio.google.com/) にアクセスし、Googleアカウントでログイン。
2. 「Get API key」をクリックしてAPIキーを発行。
3. Web管理画面の「⚙️ 設定」タブで入力して保存。

### ② LINE通知の設定（LINE Messaging API）
1. [LINE Developers コンソール](https://developers.line.biz/ja/) にアクセスし、LINEアカウントでログイン。
2. プロバイダーを作成し、「Messaging API」のチャンネルを作成（無料）。
3. 作成した公式アカウントの友だち追加QRコードを読み取り、スマホのLINEで友だち追加。
4. **Messaging API設定** タブの最下部にある「チャンネルアクセストークン（長期）」を発行してコピー。
5. **チャネル基本設定** タブにある「あなたのユーザーID（`U`から始まる英数字）」をコピー。
6. Web管理画面の「⚙️ 設定」タブに入力して保存。

---

## ⏰ 毎日の自動実行について
Windowsの「タスクスケジューラ」に `send_daily_line.bat` を登録することで、毎朝決まった時刻（例: 朝8:30や夕方17:00）に全自動でLINE通知を届けることができます。
